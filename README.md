# EasyCare+ 

A centralized, real-time monitoring web application for government hospitals across Mumbai.

## Overview
EasyCare+ allows citizens and healthcare administrators to instantly view the live status of 40+ government hospitals in Mumbai — including bed availability, ICU occupancy, and emergency status — all from a single dashboard.

## Features
- Interactive hospital map with real-time status markers
- Live bed & ICU availability tracker (available/total)
- Status indicators — Normal / Busy / Critical
- Search & filter hospitals by area or status
- Admin Dashboard to update hospital data
- Issue Reporting module for flagging problems
- Built Vanilla HTML/CSS/JS

## Tech Stack
`JavaScript` `HTML5` `CSS3` `LocalStorage API`

## Pages
- **Home** — Hero section with live stats overview
- **Hospital List** — Filterable list of all 40 hospitals
- **Hospital Details** — Per-hospital bed/ICU breakdown
- **Admin Dashboard** — Update hospital status in real time
- **Issue Report** — Submit operational issues

## Use Case
Designed for Mumbai's public healthcare infrastructure to reduce response time during emergencies by giving patients and first responders instant visibility into hospital capacity.
